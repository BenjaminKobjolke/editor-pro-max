# Per-project JSON artifacts

Every file the editing pipeline writes into `public/projects/<slug>/` (see
`docs/editor/PROJECTS.md` → "The editing pipeline"), one doc per file:

| File | Doc | Generated by |
|---|---|---|
| `video-metadata.json` | [video-metadata.md](./video-metadata.md) | `scripts/analyze-video.ts` |
| `captions.json` | [captions.md](./captions.md) | `scripts/transcribe.ts` |
| `silence.json` | [silence.md](./silence.md) | `scripts/detect-silence.ts` |
| `typing.json` | [typing.md](./typing.md) | hand-classification (see **summera-youtube-shorts** skill) |
| `silence-frames/manifest.json` | [silence-frames-manifest.md](./silence-frames-manifest.md) | `scripts/export-silence-frames.ts` |
| `timeline.json` | [timeline.md](./timeline.md) | `scripts/build-timeline.ts` |

Pipeline order: `analyze-video` / `extract-audio`→`transcribe` /
`detect-silence`→`export-silence-frames`→(hand-classify `typing.json`)→
`build-timeline`. Only `silence.json` + `typing.json` feed the actual cut
(`buildTimeline()`/`timeline.json`) — `video-metadata.json` and
`captions.json` are independent, and `silence-frames/manifest.json` is only
an index for classifying `typing.json`.
